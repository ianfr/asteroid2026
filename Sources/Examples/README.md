# Examples

Run with `swift run Examples [bennu|cohesion]` from the package root.

- `bennu` (default): Bennu plus two impactors demo, 2000 steps to
  `OUT/desktop` unless given `[output_directory] [steps]`.
- `cohesion`: calibrates the spring cohesion model at Bennu particle
  scales with three particles, comparing default and calibrated bond
  thresholds across approach speeds.
